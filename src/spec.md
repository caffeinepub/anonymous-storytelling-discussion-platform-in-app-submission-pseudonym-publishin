# Specification

## Summary
**Goal:** Simplify the global header navigation and relocate access to Reviews/Comments into a dedicated Home page section.

**Planned changes:**
- Update the global header so the top-right navigation only includes “Home” (/) and “About” (/about), removing “Read”, “Share/Share Story”, “Reviews”, and “Comments”.
- Add a “Discuss & Engage” section on the Home page (below the hero/top area) with controls for:
  - “Reviews” linking to `/discussions?mode=reviews`
  - “Comments” linking to `/discussions?mode=comments`

**User-visible outcome:** The header shows only Home and About on all pages, while the Home page provides a “Discuss & Engage” section to quickly open Discussions in Reviews or Comments mode.
